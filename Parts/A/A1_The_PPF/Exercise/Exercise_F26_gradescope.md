## Question 1 — title: `Hagrid's PPF` · 2 pts

```
One of Hagrid's unknown skills is that he's great in the kitchen. He can bake $$20$$ rock cakes ($$R$$) or $$30$$ fruitcakes ($$F$$) in one day. Set up Hagrid's PPF on an $$x, y$$ graph with rock cakes ($$R$$) on the vertical and fruitcakes ($$F$$) on the horizontal.

What is Hagrid's opportunity cost of each good?

Opportunity cost of 1R:
( ) $$2/3$$ fruitcake
(x) $$3/2$$ fruitcakes
( ) $$10$$ fruitcakes
( ) $$30$$ fruitcakes

Opportunity cost of 1F:
( ) $$3/2$$ rock cakes
( ) $$10$$ rock cakes
(x) $$2/3$$ rock cake
( ) $$20$$ rock cakes
```

## Question 3 — title: `Dynamics` · 1 pt

```
( ) $$10$$R or $$15$$F
( ) $$40$$R or $$60$$F
(x) $$20$$R or $$30$$F
( ) $$10$$R or $$30$$F
```
