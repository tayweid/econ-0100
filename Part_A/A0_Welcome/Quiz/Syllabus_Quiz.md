   ( ) Your average across homework and Checkpoints\

   ( ) A+\
   (X\) A\
   ( ) A-\

   ( ) True\
   (X\) False
4. Which are the three types of practice for each skill? Select all that apply.\
   [X] Exercises completed in class\
   [X] Vignettes completed in recitation\

   ( ) Any one of the three practice types\
   (X\) Two of the three practice types\

   ( ) One of the three practice types\
   ( ) Two of the three practice types\
   (X\) All three practice types\

   ( ) Jordan has unlocked both the first attempt and a reattempt.\
   ( ) Jordan automatically receives a no-pass for the skill.

   ( ) Skip the entire Checkpoint.\
   (X\) Take the Checkpoint and answer only the skills she has unlocked.\
   ( ) Answer every skill but expect a grade penalty.\
   ( ) Request a separate version of the Checkpoint.
9. Marcus missed practice and therefore did not unlock a skill before its Checkpoint. When may he make up that practice?\
   ( ) Immediately before the Checkpoint begins\
   ( ) During the Checkpoint\
   (X\) After the Checkpoint, in preparation for the next Reattempt\

10. Which materials may you use during a Checkpoint or Reattempt? Select all that apply.\

    [X] A nonelectronic copy of the textbook\
    [X] A calculator\
    [ ] Notes stored on your phone\
    [ ] An online AI assistant\
    [ ] Electronic textbook materials on a laptop
11. Homework and other practice are graded primarily for correctness.\
    ( ) True\
    (X\) False
12. Which statement best describes collaboration on homework?\
    ( ) It is prohibited.\
    ( ) It is permitted but discouraged.\
    (X\) It is strongly encouraged.\
    ( ) It is allowed only with written permission.
13. Which statement best represents the course’s AI policy?\
    ( ) AI use is completely prohibited throughout the course.\
    ( ) AI may complete Checkpoints as long as the student cites it.\

14. What happens during the Final Exam Period?\
    ( ) Only a cumulative traditional final exam\
    ( ) Checkpoint F only\
    ( ) A reattempt session only\

    ( ) True\
    (X\) False
