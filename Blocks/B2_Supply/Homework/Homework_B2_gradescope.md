## Question 1 — title: `Quantity Supplied` · 2 pts

```
The supply curve for butter beer can be represented by the equation $$P = 20 + \frac{1}{2} Q$$, in galleons and bottles.

a) What is the quantity supplied at 40 galleons?

( ) $$20$$ bottles
(x) $$40$$ bottles
( ) $$60$$ bottles
( ) $$80$$ bottles

b) What is the quantity supplied at 50 galleons?

( ) $$40$$ bottles
(x) $$60$$ bottles
( ) $$80$$ bottles
( ) $$100$$ bottles

c) How much did quantity supplied change as the price dropped from 50 to 40?

(x) It fell by $$20$$ bottles
( ) It rose by $$20$$ bottles
( ) It fell by $$10$$ bottles
( ) It did not change

d) What is marginal cost at a quantity of 60?

( ) $$30$$ galleons per bottle
(x) $$50$$ galleons per bottle
( ) $$60$$ galleons per bottle
( ) $$80$$ galleons per bottle
```
