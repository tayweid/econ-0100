## Question 1 — title: `Quantity Demanded` · 2 pts

```
Preferences for butter beer can be represented by the demand curve $$P_d = 100 - \frac{1}{2} Q_d$$, in galleons and bottles.

a) What is the quantity demanded at 40 galleons?

( ) $$60$$ bottles
(x) $$120$$ bottles
( ) $$160$$ bottles
( ) $$200$$ bottles

b) What is the quantity demanded at 50 galleons?

( ) $$50$$ bottles
(x) $$100$$ bottles
( ) $$150$$ bottles
( ) $$200$$ bottles

c) How much did quantity demanded change as the price dropped from 50 to 40?

( ) It fell by $$20$$ bottles
(x) It rose by $$20$$ bottles
( ) It rose by $$10$$ bottles
( ) It did not change

d) What is the marginal benefit at a quantity of 100?

( ) $$25$$ galleons per bottle
(x) $$50$$ galleons per bottle
( ) $$100$$ galleons per bottle
( ) $$150$$ galleons per bottle
```
