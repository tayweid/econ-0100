## Question 1 — title: `Equilibrium` · 2 pts

```

a) Calculate equilibrium price.

( ) $$40$$ galleons
( ) $$50$$ galleons
(x) $$60$$ galleons
( ) $$80$$ galleons

b) Find equilibrium quantity.

( ) $$40$$ bottles
( ) $$60$$ bottles
(x) $$80$$ bottles
( ) $$160$$ bottles

c) Calculate consumer surplus.

( ) $$800$$ galleons
(x) $$1600$$ galleons
( ) $$3200$$ galleons
( ) $$4800$$ galleons

d) Calculate producer surplus.

( ) $$800$$ galleons
(x) $$1600$$ galleons
( ) $$3200$$ galleons
( ) $$4800$$ galleons
```
