## Question 1 — title: `Opportunity Cost` · 3 pts

```
Colin Creevey can bake $$20$$ cornish pasties ($$P$$) or $$5$$ cauldron cakes ($$C$$) in one day. Set up Colin's PPF on an $$x,y$$ graph with pasties ($$P$$) on the vertical and cakes ($$C$$) on the horizontal. Label the axes and the intercepts.

What is Colin's opportunity cost of producing $$1$$ cake?
( ) $$1/4$$ pasty
(x) $$4$$ pasties
( ) $$5$$ pasties
( ) $$1/4$$ cake

What is Colin's opportunity cost of producing $$1$$ pasty?
( ) $$4$$ cakes
(x) $$1/4$$ cake
( ) $$1/4$$ pasty
( ) $$20$$ cakes

Which of the two does the slope of his PPF show?
(x) The opportunity cost of a cake
( ) The opportunity cost of a pasty
( ) Total output per day
( ) Neither
```

## Question 3 — title: `Next Best Alternative` · 2 pts

```
Colin has one free afternoon. He could bake for the Gryffindor party, photograph the Quidditch match, or take a nap. He'd rather bake than do either of the others, and he'd rather photograph the match than nap.

What is Colin's opportunity cost of baking?
( ) A nap
(x) Photographing the match
( ) Photographing the match and a nap
( ) Nothing: baking is his favorite

Then Dennis invites him to Hogsmeade, which Colin likes more than photographing the match but less than baking. What is his opportunity cost of baking now?
( ) Photographing the match
(x) The Hogsmeade trip
( ) The Hogsmeade trip and photographing the match
( ) A nap
```
